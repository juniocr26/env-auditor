# env-auditor

[English](README.md) | [Português brasileiro](README.pt-BR.md)

A dependency-free Python CLI that audits and synchronizes environment-file keys. Normal execution also removes keys without detected usage; review changes with `--dry-run` or use read-only `--audit-only`.
