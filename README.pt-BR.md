# env-auditor

[English](README.md) | [Português brasileiro](README.pt-BR.md)

CLI Python sem dependências externas para auditar e sincronizar chaves de arquivos de ambiente. A execução normal também remove chaves sem uso detectado; revise com `--dry-run` ou use `--audit-only` para análise somente leitura.
